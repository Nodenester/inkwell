# Inkwell

A live Markdown previewer, built autonomously by the Loomlet agent fleet (Fable 5).

This repo is one **registered project** in a multi-project LOOM fleet. A planner agent
turns the project goal into issues; a coder implements each in `ui/`; an adversarial
tester verifies against the live page; a deterministic gate merges and deploys. No human
writes the application code.

Goal: a clean, usable Markdown previewer (editor + live preview, common Markdown subset,
copy-HTML, localStorage draft persistence), pure static HTML/CSS/JS, no dependencies.

Live: https://inkwell.byttr.se
